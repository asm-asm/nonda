ANDROID お薬リマインダー

飲んだ？

朝と夜のお薬を忘れないための、シンプルな記録アプリです。下のボタンから最新版をダウンロードできます。

最新版をダウンロード

Androidスマートフォン専用です。iPhoneにはインストールできません。

安心して使えます
服用記録と設定はスマートフォン内だけに保存されます。インターネットへ送信しません。

INSTALL

インストール方法

  1. APKをダウンロード

    上の「最新版をダウンロード」ボタンを押すと、.apk ファイルのダウンロードが始まります。

  2. ダウンロードを続ける

    「危険なファイルの可能性があります」と表示された場合は、配布元が正しいことを確認して「ダウンロードを続行」を押します。

  3. ダウンロードしたファイルを開く

    通知、Chromeのダウンロード一覧、または「マイファイル」のダウンロードフォルダーからAPKを開きます。

  4. この提供元を許可

    初回だけ設定画面が開きます。「この提供元を許可」をオンにして戻り、「インストール」を押します。

  5. 通知を許可

    アプリを開き、通知の許可画面で「許可」を押します。許可しないとお薬の時間にお知らせできません。

  6. 時刻を確認

    アプリの「設定」で朝・夜の時刻と通知音を確認したら準備完了です。

SAMSUNG

通知が遅れるとき

Samsung端末では、省電力設定によって通知が遅れる場合があります。

  1. 端末の「設定」→「アプリ」→「飲んだ？」を開く
  2. 「バッテリー」→「制限なし」を選ぶ
  3. 「通知」が許可されていることを確認する

UPDATE

更新方法

新しいバージョンも同じダウンロードボタンから入手できます。新しいAPKを開いて「更新」を押してください。通常は服用記録と設定がそのまま残ります。

先にアプリをアンインストールすると記録が消えるため、更新時はアンインストールしないでください。

FAQ

よくある質問

Playストアにないのはなぜ？

現在は個人配布版のため、GitHubからAPKをインストールする方式です。

「不明なアプリ」と表示されます

Playストア以外から入れるAndroidアプリに表示される標準の確認です。このページから公式GitHub Releaseへ移動したことを確認してください。

通知音を止めるには？

通知を開いて「飲んだ」または「音を止める」を押してください。

記録は誰かに送られますか？

送られません。記録と設定は端末内だけに保存されます。

服用方法や服用量については、医師・薬剤師の指示に従ってください。
