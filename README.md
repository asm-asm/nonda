# 飲んだ？

朝・夜の服薬を記録する、Android向けリマインダーアプリです。

服用記録や設定はスマートフォン内だけに保存され、外部には送信されません。

## 主な機能

- 朝・夜の服薬時刻を通知
- 「飲んだ」ボタンによる服用記録
- 過去の服用履歴を表示
- 通知音と振動の設定
- 通知から服用済みとして記録
- ホーム画面ウィジェットから服用を記録
- アプリとウィジェットの状態を自動連動
- GitHub Releasesに新しいバージョンがあるときに通知

初心者向けのダウンロード・インストール方法は、次のページにまとめています。

Samsung端末で通知が遅れる場合は、端末の設定から本アプリのバッテリー使用を「制限なし」にしてください。

## プライバシー

- 服用記録は端末内に保存されます
- アプリの設定も端末内に保存されます
- インターネット権限はGitHub上の更新情報を確認するためだけに使用します
- 服用記録を外部サービスへ送信しません

## 通知の仕組み

朝・夜の時刻を、端末のローカル時刻でスケジュールします。

正確なアラームが許可されている場合は、`setExactAndAllowWhileIdle` を使用します。許可されていない端末では、`setAndAllowWhileIdle` に切り替えます。

通知音は「飲んだ」または「音を止める」を押すまで繰り返します。音声同士が連続しすぎないよう、発話終了後に間隔を空けています。

端末の再起動、時刻変更、タイムゾーン変更後には通知時刻を再登録します。

## 開発用ビルド

Windowsでは、プロジェクトのルートで次を実行します。

```powershell
./gradlew.bat :app:assembleDebug
```

作成されるテスト用APK：

```text
app/build/outputs/apk/debug/app-debug.apk
```

ADBで接続中の端末へインストールする場合：

```powershell
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## 確認項目

- 朝を記録した後に夜を記録しても、朝の記録が残る
- アプリを終了・再起動しても記録が残る
- 画面消灯中に通知される
- 通知の「飲んだ」「音を止める」が動作する
- ウィジェット操作がアプリへ反映される
- アプリ操作がウィジェットへ反映される
- ダークモードで文字が読める
- Fold端末の外画面・内画面で操作できる

## 注意事項

端末メーカーの省電力制御やAndroidのDoze機能により、通知が遅れる場合があります。

このアプリは服用判断や服用量の指示を行いません。服用方法については、医師・薬剤師の指示に従ってください。
